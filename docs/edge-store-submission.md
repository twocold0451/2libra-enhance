# ForumMate Edge 商店文案包

最后更新：2026-04-05

## 1. 建议的商店名称

`ForumMate 论坛增强助手`

## 2. 一句话简介

为常用论坛提供快速预览、帖子筛选和更顺手的浏览体验。

## 3. 短描述

ForumMate 是一个面向论坛场景的浏览器辅助工具，支持帖子快速预览、返回顶部、通知快速查看，以及 V2EX 的频道和标题关键字过滤。

## 4. 长描述

ForumMate 是一个专门为论坛浏览体验打造的增强工具，适合希望更高效阅读帖子、快速查看内容、减少无效信息干扰的用户。

当前版本支持以下站点：

- 2libra.com
- middlefun.com
- v2ex.com
- linux.do

核心能力包括：

- 帖子快速预览  
  无需频繁打开新页面，点击标题即可在弹窗中快速查看帖子内容。

- 通知快速查看  
  在部分站点中可直接通过弹窗查看通知内容，减少来回跳转。

- 返回顶部按钮  
  在长页面中更方便返回顶部，提升浏览效率。

- V2EX 帖子过滤  
  支持按频道中文名、频道 slug 或标题关键字过滤帖子，并支持独立规则与组合关系设置。

- 分站点独立设置  
  不同站点可以分别保存自己的开关和弹窗宽度设置，使用体验更清晰。

ForumMate 以轻量和本地化为设计原则。扩展不会要求用户注册账号，也不会默认将浏览内容上传到开发者服务器。当前版本主要使用本地存储保存用户设置，用于提供个性化的论坛增强体验。

如果你经常浏览 2libra、middlefun、V2EX 或 linux.do，希望更快看帖、少一点重复跳转、对帖子流有更多控制，ForumMate 会是一个更顺手的选择。
