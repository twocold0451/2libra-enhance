# ForumMate 隐私政策

最后更新：2026-04-05

## 1. 产品说明

ForumMate 是一个面向论坛场景的浏览器辅助工具，目前支持 `2libra.com`、`middlefun.com`、`v2ex.com` 与 `linux.do` 及其相关子域名。

ForumMate 的主要功能包括：

- 帖子快速预览
- 通知快速查看
- 返回顶部按钮
- 按频道或标题关键字过滤帖子
- 按站点保存独立设置

## 2. 我们访问哪些信息

为了实现上述功能，ForumMate 会在已支持站点的页面中读取当前页面上与功能直接相关的内容，例如：

- 当前页面 URL 与站点域名
- 帖子标题、帖子链接、通知入口等页面元素
- 用户在扩展或脚本中主动保存的设置项

这些访问仅用于在用户本地提供功能，不用于建立用户画像，也不用于向开发者上传数据。

## 3. 我们存储哪些信息

ForumMate 仅在用户本地存储与功能相关的配置数据，例如：

- 是否启用快速预览
- 是否显示返回顶部按钮
- 各站点的弹窗宽度
- V2EX 的屏蔽频道、标题关键字与规则关系

在浏览器扩展版本中，这些数据保存在浏览器提供的 `chrome.storage.local` 中。  
在 Tampermonkey 版本中，这些数据保存在 Tampermonkey 的本地脚本存储中。

## 4. 我们不会做什么

ForumMate 默认不会：

- 将用户的帖子内容、浏览记录、账号信息或设置上传到开发者服务器
- 将用户数据出售、出租或共享给第三方
- 接入广告、埋点统计或行为分析服务
- 要求用户注册账号或登录第三方服务

## 5. 第三方链接

ForumMate 中可能包含用户主动点击后打开的外部链接，例如：

- GitHub Issues / Discussions 反馈页面
- 项目主页
- 赞赏支持页面

这些页面由对应第三方网站提供，其数据处理方式适用各自的网站政策。

## 6. 权限与用途说明

浏览器扩展版本当前使用的权限包括：

- `storage`：用于在本地保存用户设置
- `activeTab`：用于在扩展弹窗中识别当前标签页所属站点，并展示对应设置

ForumMate 仅在其声明支持的站点范围内运行内容脚本。

## 7. 用户控制权

用户可以随时通过以下方式控制或删除本地数据：

- 在 ForumMate 设置界面中修改或清空相关配置
- 卸载浏览器扩展或移除油猴脚本
- 清除浏览器扩展本地存储或 Tampermonkey 脚本存储

## 8. 面向未成年人

ForumMate 不以未成年人为主要目标用户，也不会主动收集未成年人的个人信息。

## 9. 政策更新

如果 ForumMate 后续新增会影响数据处理方式的功能，本隐私政策会同步更新。
